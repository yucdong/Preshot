# Preshot 0.1.0 launch content

These are user-facing Chinese marketing drafts, independent of the English
contributor documentation. They are ready to copy into the named channels once
the installer release is available. Never claim an unsigned candidate is a
signed public release.

The four videos are reused without re-encoding from the verified 0.0.24
recordings. Their captions retain that provenance. They do not demonstrate the
project grouping/search UI added in 0.1.0. The materials use fictional Model A
and credited bridge photography.

The local handoff directory is `release-output/Preshot-0.1.0`; it contains the
installer candidate, checksums, build manifest, matching source archive,
licenses, these texts, four MP4 files, covers, GIF/PDF extras and media inventory.
Generated copies and binaries remain outside Git. The original videos remain
tracked under `docs/media`.

Publishing prerequisites are described in
[the release guide](../../docs/release/github.md). Missing Authenticode or clean-VM
acceptance must remain explicit in the handoff status. Pushing the source/tag
alone does not create a GitHub Release or upload its installer.
