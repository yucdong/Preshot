# Preshot 0.1.0

把拍摄想法、参考照片、地点、模特和道具整理成一份可执行的拍摄方案。Preshot 是 Windows 桌面应用，项目与素材保存在本地，支持中文和英文界面。

## 本版更新

- 项目支持单层分组、创建、重命名、删除与折叠，可拖拽归组，也可在项目菜单中选择目标分组。
- 中文显示“默认分组”，英文显示“Default”；自定义分组名保留用户输入。删除分组会把项目移回默认分组，项目文件保留。
- 项目名称实时搜索支持跨组查找和匹配高亮。清空搜索恢复原折叠状态，切换项目保留搜索词。
- 分组与折叠状态存入用户工作目录；旧工作区配置迁移保留备份。分组操作保留已打开编辑器的内容和撤销历史。
- 包含前序版本的 PDF 图片组分页改进。

## 可以做什么

写拍摄方案，插入参考图和地点、模特、道具卡片；拖动内容组织多栏布局；把常用内容保存到素材库并在项目间复用；导出 PDF、Word 文档和长图。

## 安装与数据

适用于 Windows 10/11 x64。下载本页 Assets 中的 `Preshot_0.1.0_x64_en-US.msi`，同时提供 SHA-256 校验文件与构建元数据。安装包界面为英文，应用支持中文和英文。

安装需要管理员权限，日常使用不需要。缺少 WebView2 时，首次安装可能需要联网。首次启动选择项目工作目录；更新前建议备份完整工作目录及项目文件夹。

0.1.0 使用工作区配置 v2；旧配置迁移会保留 `workspace.v1.backup.json`。旧应用不支持直接读取 v2 配置，请保留备份，不要让新旧版本同时操作同一工作目录。0.0.13 及更早安装系列需先卸载旧程序，用户数据会保留。
