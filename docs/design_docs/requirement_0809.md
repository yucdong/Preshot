# 插入组件按钮放在画布组件的左上角，和画布对齐
# 文案组件里面可以支持对文字大小进行调整，并随着调整文本框大小
# 组件用一个 guid id 来唯一定义，组件的名字作为一个字段加入，可以重复，文本组件可以支持拆分，拆分之后每个子文本块可以有自己的名字
# 文案组件可以支持拆分，可以拆分成左右或者上下两个文本块，分别填入不同的内容，并且可以有对应的标题块，比如这里小清新人像里面对应的"拍摄计划"，标题块可以为空，拆分之后保持整体的大小范围不变，文本块之间有一定的间隔，间隔要协调
# 当前选中文字仍然显示鼠标，我们需要鼠标显示文本编辑的形状，同时，选中文本之后，应用加粗倾斜等等似乎没有生效，需要修复
# 图片组件，除了可以用+ - 调整图片尺寸之外，也可以直接编辑尺寸的px数字，但是要限定在支持的范围内，如果超出范围则无效，还保留原来的px值
# 左侧项目栏，可以支持删除项目，删除前要确认，删除为软删除，即从总体配置中去掉这个project引用，但不删除文件，方便以后重新添加回来
# 项目也用一个guid来命名，项目的标题作为显示使用的字段，这样不同的项目就可以重复了，鼠标hook到左侧项目上面的时候会显示项目所在的地址，并显示一个按钮，打开项目所在目录
