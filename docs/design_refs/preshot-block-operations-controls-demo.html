将鼠标移动到任意 block 左侧，点击六点手柄打开完整操作菜单。支持拖拽、层级和快捷操作。

交互提示点击 `+` 插入段落；单击六点手柄打开菜单；直接拖动手柄可排序。图片组保持顶层，因此“增加缩进”会禁用。支持 Alt+↑/↓、Tab、Shift+Tab、Ctrl+D 和 Ctrl+Z。
