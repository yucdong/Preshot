Image Card · Interaction Review

This is a behavior prototype and does not modify production data. Interact directly with the image group in the middle to confirm the interaction semantics.

Current State · Image group selected

Click empty space inside the group to select it; after scrolling the middle canvas, the group toolbar closes immediately.

01 · Image-group edges and corners

All four edges can be dragged directly for single-axis changes, and corners resize width and height together; all resize hit areas stay transparent, with no visible blocks or bars. The width never crosses the body-text boundary.

02 · Single-image editing

After clicking an image, the full border becomes draggable: edges change a single axis and corners change both width and height; no blue squares or bars are shown. The delete button appears only in the upper “Image” toolbar.

Recommended selected state: darken the image-group background; for a single image show only the index, and keep delete in the image toolbar
Orange: edge aligned and snapped
03 · Source image and view

Only after double-clicking an image to open the full source image should the popover show a “Restore Size” button; the image card itself should not show it.

04 · Group-level scaling

Toolbar − / ＋ scales all images proportionally; when one row no longer fits, images wrap naturally to the next line without changing each tile's ratio.
