Implementation Rules

01
Toolbar belongs to the leaf

Each text box keeps its own persistent toolbar, participates in layout measurement, but is excluded from PDF output.

02
Auto-degrade at narrow widths

Hide text labels and low-frequency items, keeping paragraph, B/I/U, font size, color, and more.

03
Menus must not wrap

Use icon, label, and checkmark columns; keep labels single-line and size each row to its content.

04
Measure component chrome independently

Anchor the close button to the outer rect instead of the text body's natural height or internal padding.

Recommendation: use “persistent leaf toolbars + portal menus + screen-space component buttons.” This is more stable than continuing to tweak BlockNote's floating selection toolbar.
