Behavior notes
01Direct size authority
Only side-handle drag edits a loaded tile size. The ratio stays locked and width is clamped only to the full 990 px inner width.
02Immediate ordered wrap
If the next tile plus the 7 px gap cannot fit, it starts the next row. Dimensions and source order never change.
03Stable live preview
One animation-frame update repacks the whole group, so expansion pushes later images and user shrink can bring them back.
04Smart guides
Group and image edges, equal width or height, and live dimensions use 6 px entry / 10 px release hysteresis. A chosen snap becomes the explicit drag size.

Keyboard: Tab selects controls and image tiles; Enter or Space selects a tile; Escape cancels an active drag. Resizing intentionally requires direct pointer drag.

Drag left or right to resize proportionally. The whole image group reflows while dragging. Press Escape to cancel.
