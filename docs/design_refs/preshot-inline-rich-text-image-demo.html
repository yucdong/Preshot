Morning Window Portrait

Arrive on site at 08:10. First place the model near the east window to preserve the quiet interior layers, then lightly add catchlight with a white reflector.

Camera reference: 85mm, f/2.0, subject about 45° from the window.

Shoot Notes

  • Use an off-white knit for the first set and preserve the curtain texture in the background.
  • Add glass reflections in the second set and place the visual center on the right third.
  • After each set, check the highlights and eyelash focus.
