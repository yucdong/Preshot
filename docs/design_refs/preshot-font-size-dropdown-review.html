推荐：组合字号下拉

沿用当前工具栏，只调整字号控件的位置、结构和菜单密度。

控件结构

14⌄
→
数字 + 独立箭头数字区域可直接应用当前字号；右侧箭头仅负责展开菜单。
A⌄
→
字体颜色组合按钮A 下方显示当前颜色；主按钮复用颜色，箭头展开色板。

位置调整

1
移动到删除线之后与粗体、斜体、下划线归为同一组，早于段落对齐。
2
收起态不显示 px字号单位在编辑器中已明确，减少约 14px 横向占用。
3
当前字号始终可扫描使用等宽数字，菜单当前项同时用勾选和字重标识。

自定义颜色

1
更多颜色…标准色板保持紧凑，需要时再进入色相盘。
2
RGB 精确输入R/G/B 限定 0–255，HEX 同步预览；不支持透明度。

键盘行为

Enter / Space 展开↑ ↓ 移动Enter 应用Esc 关闭
