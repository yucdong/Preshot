# Preshot 0.1.0 release preparation

[Documentation index](../README.md) · [GitHub release process](github.md)

This version combines the established local planning/material/export workflow
with project grouping and name search. See [the changelog](../../CHANGELOG.md)
and [group acceptance](../test_reports/project-groups-acceptance.md).

## Source and installer

Commit all intended source, documentation and version files, then use annotated
tag `v0.1.0` for the matching source archive and build. Keep the machine-wide
x64 UpgradeCode unchanged. The handoff directory is
`release-output/Preshot-0.1.0`; generated binaries and duplicated videos are
Git-ignored. The portable handoff ZIP is beside that directory.

The installer folder includes the MSI, SHA-256 sidecar, release manifest,
matching source ZIP, MIT/GPL licenses and third-party notices. The handoff's
status file records actual signature and validation results. An unsigned build
remains a candidate, not a publishable installer. Valid Authenticode on both EXE
and MSI plus the disposable-VM lifecycle matrix are still required for publication.
Do not rewrite an unsigned manifest to claim signed or verified status.
